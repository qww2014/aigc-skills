# 题材规则、负载控制与时长算法（小节 30–43）

> 来源：《AI ACTION SCALE V6.0 FINAL 电影级动作分镜导演 Skill》小节 30–43 重构。

## 30｜真人电影动作规则

- 攻击者的动力链必须清楚：脚→髋→躯干→肩→手臂→接触。
- 命中必须有受击者身体反馈。
- 重击后攻击者也会产生惯性并需要恢复。
- 镜头不追求每一秒更快，而是“清晰→加速→命中强调→恢复”。
- 关键动作优先中景，关键结果优先近景。

## 31｜顶级3D动画规则

- 每个关键动作都有起势Pose、峰值Pose、结果Pose。
- 高速动作允许夸张，但重心和运动方向不能丢。
- 可使用极短冲击帧、Smear、速度线、残影和粒子。
- 先保证轮廓可读，再增加镜头运动。
- 动画越华丽，动作骨架越必须简单清楚。

## 32｜枪战电影规则

- 枪战必须建立“射手—目标—掩体—火力方向”的关系。
- 射击链：瞄准/暴露→射击→枪口反馈→弹着→目标反应→重新寻找位置。
- 每次射击必须改变火力关系、位置或战术。
- 换位必须有原因：原掩体失效、火力压制、角度不利、需要缩短距离。
- 镜头在射手、目标、弹着、全景战术关系之间切换。
- 避免无逻辑连续扫射和角色站在原地无限开火。

## 33｜武侠与兵器电影规则

- 长兵器：先体现距离优势，再体现回收成本。
- 短兵器：强调贴身、变线、手腕和肘部控制。
- 剑斗：剑锋碰撞必须产生偏转、滑刃、压剑或退步结果。
- 轻功：必须有起跳、空中方向、落点、落地反馈。
- 借景：墙、柱、栏杆、屋檐等只在动作需要时使用。
- 兵器攻击不能凭空改变方向；必须通过手腕、肩、身体转动或格挡结果改变。

## 34｜怪兽与机甲规则

- 巨兽：动作慢但重量大；每次移动必须影响地面、尘土、水面或建筑。
- 机甲：关节、液压、机械重量和转向成本必须可见。
- 小型高速单位与重型单位必须形成真实速度差。
- 禁止巨型对象像轻人体一样无惯性瞬移。

## 35｜车辆追逐规则

- 建立车辆A/B、道路方向、障碍物和目标。
- 转向必须产生车身侧倾、速度变化或轮胎抓地反馈。
- 碰撞必须改变车辆轨迹、速度或结构状态。
- 摄影机优先车内视角、低机位追车、侧向跟拍、前方倒退、大全景揭示空间。
- 禁止车辆无理由瞬间掉头或改变道路位置。

## 36｜多人战斗

- 多人战斗先建立空间地图，再分配攻击关系。
- 每个人都有位置、目标、攻击方向、移动方向、战术目的。
- 不要让所有人同时动作。
- 采用主动作→次级反应→空间重新组织。
- 关键人物使用中近景；群体关系使用全景。
- 多人战斗优先深景深，避免浅景深导致空间关系消失。

## 37｜一镜到底模式

一镜到底依然必须做内部Shot设计，只是这些Shot节点通过连续摄影机运动连接，而不是实际CUT。

- 节点A：建立人物运动。
- 节点B：摄影机因攻击方向改变而自然弧线转向。
- 节点C：人物穿镜形成遮挡，摄影机改变高度或距离。
- 节点D：遮挡解除，揭示新角色/环境。
- 节点E：继续继承运动方向完成高潮。

节点之间必须共享人物位置、环境位置、摄影机位置、攻击路线和移动路线。

## 38｜开场紧凑模式

当用户要求“紧凑、刺激、爽、大片、不要拖沓”：

- 0秒已经发生有效动作。
- 第一镜优先选择正在发生的动作，而不是站桩对视。
- 世界观通过运动、环境和摄影逐步建立。
- 如果需要对峙，压缩到极短，并用眼神/兵器/脚步完成信息传达。

## 39｜结尾收束模式

- 最后3秒：高潮启动→最终结果→短反馈→CUT。
- 最后0.5–1秒确认结果。
- 禁止高潮之后长时间摆Pose。
- 禁止高潮后新增动作、新技能、新战术。
- 禁止无意义慢慢拉远。
- 如果用户需要悬念，则只保留一个明确结果信息，不继续开新战斗。

## 40｜动作负载控制

AI生成最重要的稳定性原则：一个Shot不要承担过多高难度变量。

| 危险组合 | 处理 |
|---|---|
| 高速翻滚+多人+复杂技能+爆炸+360°旋转 | 拆成3–5个Shot |
| 高速兵器交叉+近景+浅景深 | 改为中近景或缩短动作 |
| 人物高速飞行+复杂空间折叠+大量特效 | 先建立空间，再释放技能 |
| 多人同时攻击 | 主动作清楚后再加入次级动作 |
| 一镜到底+大幅越轴+多人换位 | 通过前景遮挡或弧线运动重新建立空间 |

默认一个Beat = 一个主要动作 + 一个主要交互 + 一个主要结果 + 一个主要运镜变化。

## 41｜无效动作删除器

如果动作不能改变攻防、距离、位置、速度、重心、武器、战术、空间或环境，就删除。

例如：“挥手摆Pose”没有结果→删除；“挥手→空间折叠→攻击路线改变→保留”。

## 42｜用户语言翻译器

| 用户说 | 系统自动翻译 |
|---|---|
| 炫酷 | 清晰轨迹+连续动作链+距离变化+速度曲线+合理运镜+关键慢动作+环境反馈+高潮 |
| 电影感 | 合理焦距+自然景深+真实物距+平滑轨迹+稳定摄影+空间层次+光影 |
| 震撼 | 尺度+空间+环境+镜头距离+高低差+巨大对象+Reveal |
| 丝滑 | 连续轨迹+Smooth Ease+自然惯性+主体跟随+轻微弧线+稳定水平线 |
| 真实 | 重量+惯性+重心+动作准备+受击反馈+克制特效 |
| 动漫 | Pose清晰+速度夸张+冲击帧+Smear+更强透视 |
| 快 | 缩短动作准备+加速+跟拍+更紧景别，不等于疯狂切镜 |
| 慢 | 延长准备/结果确认，不等于整段慢动作 |

## 43｜时长算法

| 时长 | 推荐结构 |
|---|---|
| 3秒 | 动作→结果 |
| 5秒 | 冲突→攻击→防守/反应→结果 |
| 10秒 | 冲突→动作链→反击→小高潮 |
| 15秒 | 立即冲突→第一轮交锋→连续动作→战术变化→升级→高潮→CUT |
| 30秒 | 冲突→第一轮→连续攻防→距离/战术变化→反转→第二阶段→终极能力→最终碰撞→结果 |
| 60秒+ | 按阶段拆成多个15–20秒动作段，每段必须有自己的小高潮 |
