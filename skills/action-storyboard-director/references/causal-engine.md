# 因果引擎与动作物理（小节 01–17）

> 来源：《AI ACTION SCALE V6.0 FINAL 电影级动作分镜导演 Skill》小节 01–17 重构。

## 01｜最高使命

AI ACTION SCALE V6.0 必须同时承担以下导演职能：

- **动作导演**：决定动作目的、攻防、节奏、战术与高潮。
- **武术指导**：决定拳脚、兵器、步法、距离、受力和动作合理性。
- **特技指导**：决定跳跃、跌落、碰撞、翻滚、环境借力和安全可执行的身体逻辑。
- **动作分镜导演**：把动作拆成可拍摄的Shot，并规定每个镜头只承担明确视觉任务。
- **摄影指导**：决定景别、机位、焦距、光圈、物距、景深和摄影机运动。
- **剪辑指导**：决定何时切镜、从什么动作切入、用什么结果交给下一镜。
- **动画动作导演**：控制Pose、速度曲线、动作峰值、夸张程度和可读性。
- **VFX导演**：所有特效必须有动作、能力或环境来源。
- **AI视频导演**：控制单镜头动作负载、角色一致性、空间连续性和生成稳定性。
- **Prompt工程师**：把完整设计压缩成AI模型真正能执行的语言。

## 02｜十二条最高原则

1. **动作第一**：先解决谁为什么做什么，以及动作造成什么结果。
2. **因果第一**：后一动作必须由前一动作产生的结果推动。
3. **分镜第一**：任何超过3秒的复杂动作都必须先拆Shot。
4. **动作连续性高于动作数量**：宁可少一个动作，也不能断掉速度、方向、重心、位置、武器和战术。
5. **摄影机服务动作**：看清、强化速度、展示空间、强调重量、制造冲击、引导视线，但不抢动作。
6. **受力必须可见**：攻击、格挡、碰撞、跌落、反弹、技能命中都必须产生身体或环境反馈。
7. **特效是反馈**：不能让特效替代动作。
8. **每个动作必须改变至少一项**：攻防、距离、位置、速度、重心、武器、战术、空间或环境。
9. **开头紧凑**：用户要求刺激、爽、大片时，第一秒就进入有效动作。
10. **中段升级**：必须发生至少一次战术变化；高级动作戏优先“优势→破解→反制→再反制”。
11. **结尾收束**：最后2–3秒进入高潮，最后0.5–1秒确认结果后CUT。
12. **先逻辑，后炫技**：任何随机旋转、无因果位移、无理由特效、无理由切镜都删除。

## 03｜核心动作因果引擎

每一个关键动作必须通过六步检查：

| 阶段 | 必须回答 | 示例 |
|---|---|---|
| 意图 | 角色为什么做？ | A想逼B离开掩体 |
| 动作 | 具体怎么做？ | A侧身探出、连续射击 |
| 交互 | 与谁/什么发生关系？ | 子弹压制B的掩体边缘 |
| 结果 | 发生了什么？ | B无法继续停留 |
| 反馈 | 身体/武器/环境发生什么？ | 碎屑飞散，B改变重心 |
| 下一动作 | 为什么现在做下一步？ | B借另一侧掩体转移 |

- 禁止：A攻击→B闪避→A突然换位置→B突然大招。
- 正确：A攻击→B闪避→A攻击落空产生惯性→B抓住空档→B反击→A被迫改变重心→利用环境恢复→再次攻击。

## 04｜电影分镜核心：Shot Engine

V6.0的最小电影单位不是“动作”，而是 Shot。每个Shot必须有：

1. SHOT编号
2. 时间码：精确到0.1秒
3. 景别
4. 机位高度与角度
5. 镜头焦距
6. 物距
7. 主要摄影机轨迹
8. 画面主任务
9. 人物动作
10. 交互对象
11. 结果与受力
12. 环境反馈
13. 速度曲线
14. 剪辑入口
15. 剪辑出口
16. 下一Shot如何继承方向、位置和速度

一个Shot原则：一个主要动作 + 一个主要结果 + 一个主要摄影任务。复杂动作必须拆Shot。

## 05｜五套电影动作语言

| 类型 | 核心审美 | 必须突出 | 默认镜头语言 |
|---|---|---|---|
| 真人电影动作 | 真实重量、惯性、身体受力 | 起手、接触、受击、恢复 | 35mm主力，中景/近景，克制运镜 |
| 顶级3D动画 | Pose清晰、节奏鲜明、视觉夸张 | 关键Pose、动作峰值、冲击帧 | 24–35mm动态镜头，允许更强透视 |
| 枪战电影 | 战术关系、火力与掩体 | 射手/目标/掩体/弹着/换位 | 24–50mm交替，空间镜头与反应特写 |
| 武侠/兵器 | 距离、兵器攻击线、借力 | 剑线、格挡、回收、步法 | 28–50mm动作主镜，85mm命中/眼神 |
| 空间/超能力 | 规则改变战斗结果 | 能力触发、轨迹改变、尺度升级 | 近景规则说明→中景结果→24mm大全景 |

## 06｜创意解析器

收到用户一句话后自动解析：

- 主体 / 人数 / 身份 / 体型 / 战斗关系
- 战斗目的 / 胜负条件 / 情绪
- 动作类型 / 武器 / 能力 / 世界规则
- 场景 / 时间 / 天气 / 地形 / 环境可利用物
- 视觉媒介 / 写实程度 / 动画程度 / 色彩 / 光影
- 时长 / 节奏 / 开场要求 / 高潮要求 / 结尾要求
- 镜头偏好 / 一镜到底或多镜头 / 是否要求第一人称
- 用户明确指定的任何镜头、焦距、光圈、动作、角色和风格

**用户没有提供的参数，由高级电影默认值自动补全；用户明确提供的参数必须优先。**

## 07｜动作类型识别

- **REALISTIC_HAND_TO_HAND**：写实拳脚、MMA、街头格斗、军警近战。
- **REALISTIC_WEAPON**：写实刀、剑、棍、斧、匕首等。
- **WUXIA_WEAPON**：武侠兵器、轻功、环境借力。
- **XIANXIA_COMBAT**：仙侠兵器、灵力、飞行、法术。
- **SPACE_RULE**：空间折叠、距离改变、方向翻转、攻击轨迹改变。
- **SUPERPOWER**：强化身体、冲击、飞行、能量攻击。
- **MAGIC_COMBAT**：元素、法阵、召唤、魔法。
- **FIREARM_COMBAT**：枪械、掩体、战术移动、火力关系。
- **CREATURE_COMBAT**：巨兽、生物结构、重量和环境反馈。
- **MECHA_COMBAT**：机械关节、液压、金属惯性。
- **VEHICLE_CHASE**：车辆、转向、抓地、碰撞、速度。
- **WAR_TACTICAL**：队形、火力、掩体和空间控制。
- **SPORT_ACTION**：体育动作、器械和竞技规则。

## 08｜Combat DNA

每名角色自动建立 Combat DNA：

- ID / 身高 / 体型 / 重量感 / 力量 / 速度 / 敏捷 / 耐久
- 攻击距离 / 移动方式 / 战斗流派 / 主武器 / 副武器
- 技能 / 防御方式 / 反击方式 / 优势 / 弱点
- 心理状态 / 战斗目的 / 风险偏好 / 终结方式

两名角色必须具有真实可见的战斗差异。例如：**A轻快、短兵器、闪避反击；B厚重、长兵器、压迫推进**。差异必须真正改变动作，而不是只写在人物设定里。

## 09｜战术关系系统

- 默认战术循环：观察 → 试探 → 攻击 → 防守 → 反击 → 改变战术 → 获得优势 → 对手升级 → 第二阶段 → 高潮。
- 高级战斗优先：优势 → 破解 → 反制 → 再反制。
- 禁止：A打一下→B打一下→A打一下的机械轮流。
- 至少一次战术变化；15秒以上动作戏建议至少一次明显优势逆转。

## 10｜战斗距离系统

| 距离 | 定义 | 主要动作 |
|---|---|---|
| D0 | 超远 | 观察、远程攻击、巨大能力 |
| D1 | 远 | 冲刺、投射、枪械、长兵器 |
| D2 | 中 | 标准攻防、剑术、拳脚 |
| D3 | 近 | 连续攻击、肘膝、短兵器 |
| D4 | 贴身 | 压制、闪避、短距离反击 |
| D5 | 擒抱 | 摔投、锁技、控制 |
| D6 | 空中 | 飞跃、空中攻防、坠落 |

距离变化必须由战术结果产生，不机械套用“远→中→近”。

## 11｜动作物理与重量

写实或半写实动作默认遵循：**准备 → 启动 → 加速 → 接触 → 受力 → 惯性 → 恢复**。

- 轻型角色：启动快、停止快、惯性小。
- 普通人体：自然脚步、重心和惯性。
- 重型角色：启动慢、停止慢、碰撞重。
- 巨兽：巨大惯性、地面震动、环境变形。
- 机甲：关节延迟、液压反馈、金属碰撞和机械惯性。

跌落、跳跃、翻滚必须存在起始、空中轨迹和落地反馈。

受击必须影响身体方向、重心或位置，禁止只做“后退一米”的无物理位移。

## 12｜武器物理系统

每种武器自动建立：握持方式、起手、攻击轨迹、攻击距离、速度、回收、守法、碰撞结果、重量、惯性、重心、最佳摄影角度。

| 武器 | 重点 |
|---|---|
| 长兵器 | 距离控制、攻击半径、回收成本、枪尾/棍尾变化 |
| 短兵器 | 贴身、快速变线、手腕控制 |
| 重型武器 | 蓄力、惯性、转向成本、命中后恢复 |
| 双手武器 | 整体发力、重心变化、回收 |
| 剑/刀 | 攻击线、格挡角度、滑刃、偏转、距离 |
| 远程武器 | 射界、暴露、火力关系、换位 |

## 13｜交互结果数据库

- **人体↔人体**：格挡、闪避、失衡、抓取、压制、摔倒、反击窗口。
- **武器↔武器**：弹开、滑开、卡住、缠绕、偏转、脱手。
- **武器↔环境**：划痕、火星、反弹、卡住、断裂、穿透。
- **人体↔环境**：撞墙、踩墙、滑倒、借力、翻越、掩体变化。
- **能力↔环境**：烟尘、碎片、地面震动、建筑反馈、光照变化、空间变化。

每次交互必须留下可追踪后果。

## 14｜环境战斗

环境不是背景，而是战斗资源。自动识别墙、柱、门、楼梯、栏杆、车辆、玻璃、树、屋檐、泥、水、雪、沙、岩石等。

正确链：动作 → 环境交互 → 环境反馈 → 下一动作。

- 借墙→反弹→重新进入攻击线。
- 撞墙→受力→失衡→恢复或反击。
- 踩墙→起跳→改变攻击高度。
- 桌面/栏杆→改变高度或阻挡攻击。
- 掩体→改变火力关系→迫使对手换位。

禁止随机砸墙、随机爆炸、随机碎片。

## 15｜空间规则与超能力

仅在空间战、仙侠、超能力等题材启用。空间变化必须属于：距离压缩、距离拉伸、方向翻转、空间连接改变、空间折叠、攻击路线弯曲、出口重定向。

**硬规则：空间变化必须改变战斗结果。**

- 正确：攻击→空间弯曲→攻击路线偏转→对手判断改变→利用新路线反击。
- 禁止：正常打斗+背景突然出现空间裂缝，但没有任何战斗后果。

## 16｜技能系统

技能结构：准备 → 聚能/启动 → 动作 → 释放 → 轨迹 → 命中/作用 → 冲击 → 环境反馈 → 余波。

| 等级 | 定位 | 升级方式 |
|---|---|---|
| L1 | 普通攻击 | 身体动作 |
| L2 | 强化攻击 | 动作+受力升级 |
| L3 | 特殊技能 | 加入规则变化 |
| L4 | 大范围技能 | 扩大空间与环境反馈 |
| L5 | 终极技能 | 动作、空间、摄影、环境、特效同时升级 |

技能升级必须同时升级动作规模、空间规模、摄影机尺度、环境反馈和特效层级；不能只把特效做大。

## 17｜特效系统

| 层级 | 内容 | 适用 |
|---|---|---|
| VFX01 | 微粒、火星、灰尘 | 轻微碰撞 |
| VFX02 | 动作拖尾、残影 | 高速动作 |
| VFX03 | 武器能量 | 兵器/能力 |
| VFX04 | 技能释放 | 特殊技能 |
| VFX05 | 环境级冲击 | 大规模命中 |
| VFX06 | 大范围毁伤 | 建筑/地面/战争 |
| VFX07 | 世界级终极效果 | 终极技能 |

视觉升级顺序：动作层次 → 距离变化 → 速度变化 → 摄影机变化 → 空间变化 → 环境反馈 → 特效。
