# 景别组合配方库

15 套 2–6 镜的景别序列，每套对应一类"要讲清的事"和一种情绪走向。只管**景别顺序与镜头数量**，不管焦距、机位高度、运镜。

## 何时调用

- 用户问"这场戏分几个镜头""几个镜头讲清一件事"
- 用户问"远中近特怎么排""景别顺序""这几个镜头怎么接"
- 用户问"按情绪选镜头"——要干脆 / 温暖 / 震撼 / 好奇 / 专注 / 运动感
- 用户要现成的分镜组合模板、分镜配方、镜头序列参考
- 用户拿着一个具体场景问"这段怎么分镜"

**不要**给摄影机参数、焦距、机位高度、动作因果设计——本技能只管景别顺序与镜头数量。

## 怎么用

1. **先选要讲清的事和想传达的情绪，再选组合。** 不是先凑满 6 镜，再给每一镜编理由。
2. **"3 镜"指 3 个镜头，不是必须使用 3 种不同景别。** 景别可以重复。
3. **每一镜都要提供新信息。** 只把同一张图连续放大一点，不算一个新镜头。
4. 下面的案例是**原创练习方案**，情绪效果是**创作目标**，不是套上组合就一定产生的效果。

## 景别五档速查

| 景别 | 取景范围 | 适合表现什么 |
|---|---|---|
| 远景 | 环境占主导，人物较小 | 交代地点、空间规模、人物与环境的关系；孤独、自由、壮阔 |
| 全景 | 人物从头到脚完整入画 | 全身动作、站位、走动，以及两个人之间的距离 |
| 中景 | 通常取人物腰部以上 | 手部动作、人物互动、日常对话；动作在腰部以下时需要适当放宽画面 |
| 近景 | 通常取人物胸部或肩部以上 | 看清眼神、神情和情绪变化 |
| 特写 | 突出面部或一个关键局部，如眼睛、手、钥匙、手机消息 | 强调重要信息和动作细节 |

这些是入门时的常见划分，具体边界会随教材和拍摄对象有所变化。"远景"不等于只要用广角，"特写"也不等于必须把背景全部虚化。

## 四条 AI 套用原则

1. **先写目的，再选组合。** 例如"让观众看懂她发现戒指"，就围绕"停下—看向地面—戒指"选镜头。不是先凑满 6 镜，再给每一镜编理由。
2. **景别顺序不是禁令。** 远景可以直接接特写，中景也可以接近景。是否自然，要看新信息、动作、视线和切换时机。同角度、同动作、同信息只突然放大一点，才容易产生不必要的跳动感。
3. **画面要接上，不能只靠景别。** 检查人物、服装、道具、光线、位置和动作方向。连续动作切在进行中，前一镜没做完的动作，后一镜接着完成。
4. **生图与视频动作分开写清。** 单张分镜图写"当前这一瞬间"；图生视频再写"从什么动作开始，到什么状态结束"。不要让一张图同时表现拿钥匙、出门和上车。

## 单镜写法

一镜的简短写法：`人物与固定服装＋景别＋人物位置＋当前动作＋场景与光线`。

视频动作补充：`动作从哪里开始、朝哪个方向进行、在哪里结束`。
