# Screenplay Production

## 子模式

- `freeform`：读取 `oac-screenwriting/SKILL.md`
- `structured-short-drama`：读取 `novel-script/SKILL.md`

通用剧本重场景、动作、对白和潜台词；结构化模式重 `script.json`、节拍秒数、角色/场景对账和质量门。不要在剧本层提前写镜号或视频模型语法。
