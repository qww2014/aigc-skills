# AI 分镜套用时，记住这几件事

## 1. 先写目的，再选组合

例如"让观众看懂她发现戒指"，就围绕"停下—看向地面—戒指"选镜头。不是先凑满 6 镜，再给每一镜编理由。

## 2. 景别顺序不是禁令

远景可以直接接特写，中景也可以接近景。是否自然，要看新信息、动作、视线和切换时机。同角度、同动作、同信息只突然放大一点，才容易产生不必要的跳动感。

## 3. 画面要接上，不能只靠景别

检查人物、服装、道具、光线、位置和动作方向。连续动作切在进行中，前一镜没做完的动作，后一镜接着完成。

## 4. 生图与视频动作分开写清

单张分镜图写"当前这一瞬间"；图生视频再写"从什么动作开始，到什么状态结束"。不要让一张图同时表现拿钥匙、出门和上车。

## 一镜的简短写法

- 一镜的简短写法：`人物与固定服装＋景别＋人物位置＋当前动作＋场景与光线`。
- 视频动作补充：`动作从哪里开始、朝哪个方向进行、在哪里结束`。

## 一句总纲

组合不是情绪开关。表演、构图、光线、声音和剪辑节奏，都要朝同一个表达目的配合。
