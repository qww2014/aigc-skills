# 15 套景别组合配方

按镜头数量递进：**2 镜 = 01–03**（迅速说明一件事）、**3 镜 = 04–06**（建立一个清楚的小段落）、**4 镜 = 07–09**（让行动、信息和结果连起来）、**5 镜 = 10–12**（分层推进，不必每镜都换一种景别）、**6 镜 = 13–15**（适合有起因、有行动、有结果的小故事）。

每一套给出：场景、情绪目标、逐镜画面、连接关键、AI 提醒。逐镜内容为原资料照抄，未做压缩。

---

## 01｜中景 → 特写

场景：出门拿钥匙、按按钮、打开礼物。
情绪目标：干脆、有重点。
第1镜：中景，男人伸手去拿桌上的车钥匙。
第2镜：特写，手指抓住钥匙并将它提起。
连接关键：从"伸手"切到"抓住"，动作继续往下走，不要重新伸一遍。
AI提醒：固定用哪只手、钥匙的位置和移动方向。

---

## 02｜特写 → 近景

场景：收到好消息、看到照片、发现意外信息。
情绪目标：惊喜、温暖，也可用于失落。
第1镜：特写，手机显示"我到楼下了"。
第2镜：近景，女孩读完消息，抬头露出笑容。
连接关键：先让观众知道她看到了什么，再看她的反应。
AI提醒：保留看手机到抬头的过程；准确文字建议后期添加。

---

## 03｜特写 → 远景

场景：旅行地点揭晓、露营、宏大环境展示。
情绪目标：意外、震撼、豁然开朗。
第1镜：特写，一只手将咖啡杯放在木桌上。
第2镜：远景，揭示木桌位于高山营地，人物面对整片云海。
连接关键：杯子、木桌和光线对应得上，观众才知道这是同一个地点。
AI提醒：保留同款杯子和桌面，别把远景生成成另一个营地。

---

## 04｜远景 → 中景 → 特写

场景：发现物品、寻找线索、注意到重要细节。
情绪目标：好奇、逐步关注。
第1镜：远景，雨后街道上，男子突然停下脚步。
第2镜：中景，他弯腰，视线落向地面。
第3镜：特写，水洼旁躺着一枚金色戒指。
连接关键：环境 → 寻找动作 → 被发现的东西。
AI提醒：固定戒指相对水洼的位置；人物视线要指向它。

---

## 05｜特写 → 中景 → 远景

场景：音乐表演、旅行、具有反差的地点揭晓。
情绪目标：从专注走向开阔、惊艳。
第1镜：特写，手指按下钢琴琴键。
第2镜：中景，女孩坐在钢琴前弹奏。
第3镜：远景，揭示钢琴位于面朝大海的露台。
连接关键：从细节认出人物，再看见完整环境。
AI提醒：钢琴型号、人物服装和受光方向保持一致；琴声可以贯穿三镜。

---

## 06｜全景 → 近景A → 近景B

场景：朋友商量、情侣交流、人物提出请求。
情绪目标：真诚、关心、关系变化。
第1镜：双人全景，两位朋友坐在长椅两端。
第2镜：A的近景，她问："明天你能陪我去吗？"
第3镜：B的近景，他看着她，点头答应。
连接关键：先看清两人位置，再分别看说话与回应。
AI提醒：两人的视线要相对；切镜后不要无故交换左右位置。

---

## 07｜中景 → 特写 → 近景 → 全景

场景：车站接人、约会重逢、见到久别的朋友。
情绪目标：期待 → 惊喜 → 释放。
第1镜：中景，女孩在人群边寻找来接她的人。
第2镜：特写，她的手机收到"看你右边"。
第3镜：近景，她向右看去，眼睛亮起来。
第4镜：双人全景，她走向朋友，两人拥抱。
连接关键：消息引导视线，视线引出人物，最后完成相见。
AI提醒：朋友的位置要与女孩转头方向对应，不能突然出现在另一边。

---

## 08｜全景 → 中景 → 特写 → 全景

场景：咖啡制作、料理、手作与操作展示。
情绪目标：专注、完成后的满足。
第1镜：全景，咖啡师站在操作台前，工作空间清楚可见。
第2镜：中景，他拿起奶缸，开始往咖啡杯里倒奶。
第3镜：特写，奶流在杯面形成清晰的拉花。
第4镜：全景，他将完成的咖啡递给顾客。
连接关键：在哪儿做 → 怎么做 → 关键细节 → 成品交付。
AI提醒：杯子、左右手、液面与拉花进度要连续。

---

## 09｜中景 → 特写A → 特写B → 远景

场景：出门上车、旅行出发、快速跨过路程。
情绪目标：利落、有行动感。
第1镜：中景，男人背上包，走向房门。
第2镜：特写A，他握住房门把手，开始拉开。
第3镜：特写B，切到车门把手，手以相近方向拉开车门。
第4镜：远景，汽车驶离停车位。
连接关键：用相似动作连接不同地点，省去下楼和走路。
AI提醒：两次拉动的画面位置、方向和速度尽量对应。这是跨场景匹配，不是同一扇门。

---

## 10｜远景 → 全景 → 中景 → 近景 → 特写

场景：街头演奏、工匠工作、专注的人物介绍。
情绪目标：逐步沉浸、越来越关注人物。
第1镜：远景，午后的广场上，有人在拉小提琴。
第2镜：全景，看清演奏者的站姿与身体律动。
第3镜：中景，看清拉弓与持琴的动作。
第4镜：近景，看见她投入演奏的神情。
第5镜：特写，手指在琴弦上快速变换位置。
连接关键：每靠近一层，都增加一种值得看的信息。
AI提醒：不能只把同一张图连续放大；每一镜应有对应的动作或信息。

---

## 11｜特写 → 近景 → 中景 → 全景 → 远景

场景：户外写生、自然旅行、环境逐层揭晓。
情绪目标：好奇 → 轻松 → 开阔。
第1镜：特写，画笔在画布上涂下一抹蓝色。
第2镜：近景，画者抬眼，观察画布外的景物。
第3镜：中景，看见她坐在画架前继续作画。
第4镜：全景，看清她坐在湖畔草地上，身边放着画具。
第5镜：远景，揭示眼前的整片湖泊与雪山。
连接关键：画布上的蓝色，在最后与湖水呼应。
AI提醒：最后的湖山要与前面画布内容相符。第4镜没有新信息时可以删掉。

---

## 12｜全景 → 近景A → 近景B → 特写 → 全景

场景：朋友鼓励、家人和解、有人伸出援手。
情绪目标：犹豫 → 被理解 → 安心。
第1镜：双人全景，两位朋友隔着桌子坐着。
第2镜：A的近景，她低头说："我有点不敢去。"
第3镜：B的近景，他回应："我陪你。"
第4镜：特写，B将自己的手伸过桌面，A握住。
第5镜：全景，两人一起起身离开。
连接关键：对话提出问题，用实际行动给出回应。
AI提醒：双手来自正确的人和方向；最后一镜要表现关系已经发生变化。

---

## 13｜远景 → 全景 → 中景 → 特写 → 近景 → 全景

场景：归还失物、日常善意、城市温暖小故事。
情绪目标：担心 → 发现希望 → 感动。
第1镜：远景，车站外，一名女孩着急地四处张望。
第2镜：全景，她走回长椅旁寻找。
第3镜：中景，她翻找包里的夹层，仍没有找到钱包。
第4镜：特写，一只手将她的钱包递进画面。
第5镜：近景，她抬头，紧张的表情放松下来。
第6镜：双人全景，她接过钱包，向归还者道谢。
连接关键：先让观众看懂她在找东西，再用钱包和反应完成揭晓。
AI提醒：钱包外观固定，归还者在最后一镜的位置要承接递钱包的方向。

---

## 14｜特写 → 中景 → 特写 → 中景 → 近景 → 全景

场景：耳机、相机、运动装备等产品的真实使用。
情绪目标：期待 → 投入 → 轻松。
第1镜：特写，手打开耳机盒。
第2镜：中景，女孩取出耳机并戴好。
第3镜：特写，手指轻触耳机控制区。
第4镜：中景，她将手机收进口袋，背好包。
第5镜：近景，她听到音乐，轻轻跟着节奏点头。
第6镜：全景，她迈步走出房间。
连接关键：产品细节必须服务于使用过程，最后落到人物的状态。
AI提醒：固定左右耳、产品形状与触控位置；音乐进入的时点与操作对应。

---

## 15｜全景 → 特写 → 中景 → 全景 → 近景 → 远景

场景：篮球投篮、训练挑战、完成一个运动目标。
情绪目标：准备 → 紧张 → 成功后的释放。
第1镜：全景，女孩站在罚球线，篮筐位置清楚。
第2镜：特写，她调整握球的手指。
第3镜：中景，她举球、伸臂，将球投出。
第4镜：全景，篮球继续飞行并落入篮筐。
第5镜：近景，她露出开心、松一口气的表情。
第6镜：远景，朋友从场边跑来与她庆祝，结束这一小段。
连接关键：一球只投一次，下一镜接后续阶段，情绪在进球之后出现。
AI提醒：固定投篮方向、篮筐位置与球的轨迹；不要在第4镜重新开始投球。

---

## 按情景与情绪快速选

- 要干脆利落、突出关键动作：01、09。
- 要温暖惊喜、看到人物反应：02、07、12、13。
- 要震撼、开阔、逐步揭晓环境：03、05、11。
- 要好奇、逐步寻找答案：04。
- 要讲清对话和人物关系：06、12。
- 要看懂操作、产品或制作过程：08、14。
- 要专注、沉浸、认识一个人物：10。
- 要运动感、紧张感与成功后的释放：15。

组合不是情绪开关。表演、构图、光线、声音和剪辑节奏，都要朝同一个表达目的配合。
