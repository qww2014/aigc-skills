# AIGC 核心制作技巧

这份参考规范把高频的影视生成稳定性方法整理成一套跨模型、跨工具的生产控制层。它不替代 H3、Seedance、Wan 3.0 的提示词协议，也不自动授权出图、付费生成、上传或提交任务。

## 使用方式

先确定当前产物是资产、空间/镜头、预演还是动作，再只读取对应的既有专项 Skill：

| 技巧 | 主要落点 |
|---|---|
| 角色资产、声音资产 | `aigc-asset-bible`、`character-refs`、`hell-grind-aigc-skill` |
| 场景资产、空间地图、大小参考 | `novel-art`、`hell-grind-aigc-skill` 的空间与连续性参考 |
| 预演镜头、摄影参数 | `storyboard-and-action`、`visual-direction` |
| 真实物理运动 | `hell-grind-aigc-skill` 的动作物理与视频提示词参考 |

## 八项方法

### 1. 角色资产：按视图和状态拆分

- 为每个主要角色建立高清面部近景、正面全身和背面全身视图。
- 局部细节变化优先使用蒙版、局部编辑或派生视图；不要为了改一个局部特征而整张图重生成。
- 正常、受伤、换装、湿身或携带关键道具等状态，建立独立资产版本，并记录状态差异和可继承的身份特征。
- 角色参考图以已确认的锚点为根，派生视图不得反过来覆盖锚点。

### 2. 声音资产：固定文字描述，先做稳定性测试

- 不把单一音色文件当作唯一身份依据；用固定文字描述记录音高、音色、年龄感、口音、语速、力度和情绪范围。
- 示例：`低沉粗粝的男中音，带伦敦街头口音，平静中带威胁`。
- 在正式生成前，用短句测试不同语速、口音和情绪下的稳定性，记录可接受范围。
- 台词、歌声、环境声和非叙事配乐要分层描述，避免把声音身份与单次生成结果混为一谈。

### 3. 场景资产：优先三分之四视角和锚点物

- 场景资产优先从三分之四侧面或能呈现纵深的角度建立，避免只有正面平视造成空间扁平。
- 在场景中加入柱子、沙发、门框、灯具、台阶等明显参照物，并在场景账本中固定其用途和位置。
- 场景参考图用于锁定空间结构；改变氛围或光线时，尽量保留锚点物、入口方向和主要比例。

### 4. 空间地图：把关系写成可验证的文字

- 用文字标注主体、参照物、距离、左右/前后关系和可通行路径，例如：“平台在画面中央，巨石在平台右侧约三米”。
- 同时记录摄影机位置、朝向、视线高度、主光方向、补光方向和关键遮挡。
- 多主体镜头先固定空间关系，再写动作；不要只写“电影感”或“合理站位”。
- 跨镜头持续检查主体位置、屏幕方向、道具状态和光线方向，防止空间关系漂移。

### 5. 预演镜头：先建立空间，再进入近景

- 一场戏或一段连续动作的开头，优先安排约 1 秒的全景/建立镜头，先让模型确认主体、场景和相互位置。
- 再切入中景、近景或特写；特写不能承担模型尚未确认的空间信息。
- 预演镜头的任务是确认位置、方向、进入/退出路径和光线，不是单纯增加镜头数量。
- 对高风险动作、多人交互或复杂场景，先输出低成本预演，再进入正式视频提示词。

### 6. 大小参考：使用关系式尺度

- 不只写抽象数字；用汽车、门、楼层、人物、桌面等已知参照物表达尺寸和距离。
- 示例：`30 米高的巨人，手掌约与汽车同宽，头部伸进屋顶上方的黑暗中`。
- 同一镜头内保持参照物的尺度一致；如果比例发生变化，明确写出是镜头透视、主体移动还是实际变形。

### 7. 摄影参数：数字与画面结果同时写

- 可用视角或镜头角度表达空间效果，例如约 `84°` 广角、`47°` 正常视角、`29°` 人物长焦、`8°` 超长焦；数字是意图提示，不是跨平台的绝对物理保证。
- 必须同时描述画面结果：摄影机离人物很远但得到面部特写、背景被压缩、前景比例夸张、景深变浅或空间被拉平。
- 先写主体关系和画面结果，再补焦段、角度、光圈或运动；不要堆参数代替导演意图。
- 真实 Dolly、轨道移动、摇臂、手持和数字 Zoom 要区分，避免把不同运动混成一个词。

### 8. 真实物理运动：描述材质、受力和反馈

- 动作描述要包含材质特性、重力、惯性、接触、受力、阻力和结果。
- 示例：`粘液具有明显黏性，沿重力方向缓慢拉丝滴落`；`沉重手臂下坠，肩膀被重量向下牵拉，动作停止后仍有惯性回摆`。
- 复杂动作按“动作 → 接触/受力 → 结果 → 反馈 → 下一动作”组织；特效不能替代主体动作和因果。
- 与其反复写“真实感”“电影感”，不如写清楚运动为什么发生、如何停止以及环境如何响应。

## 交付前检查

- 角色视图和状态是否有版本记录，锚点是否被保护。
- 声音描述是否固定，语速/口音测试是否有结果。
- 场景是否有三分之四视角和可定位的锚点物。
- 空间地图是否同时写主体关系、摄影机和光线。
- 是否先用建立镜头确认空间，再进入近景或特写。
- 尺度是否通过关系式参照物表达。
- 摄影参数是否同时说明可见画面结果。
- 动作是否写明材质、受力、惯性和环境反馈。
