# 分镜、剪辑与摄影机（小节 18–29）

> 来源：《AI ACTION SCALE V6.0 FINAL 电影级动作分镜导演 Skill》小节 18–29 重构。

## 18｜电影分镜结构

默认15秒不是一条动作Prompt，而是一组有剪辑意义的Shot。

| 时间 | 常见任务 | 镜头重点 |
|---|---|---|
| 0.0–1.0 | 冲突已经发生 | 第一有效动作 |
| 1.0–3.0 | 第一轮攻防 | 建立空间+动作 |
| 3.0–5.5 | 动作链 | 近景/中景交替 |
| 5.5–7.5 | 战术变化 | 优势转移 |
| 7.5–10.5 | 升级 | 空间或速度升级 |
| 10.5–12.5 | 关键反击 | 命中/技能 |
| 12.5–14.2 | 高潮 | 结果最大化 |
| 14.2–15.0 | 确认 | 短反馈+CUT |

此表是节奏骨架，不是机械模板。具体时间必须根据动作复杂度调整。

## 19｜Shot设计规则

- **建立空间Shot**：告诉观众人物在哪里、朝哪边运动。
- **攻击Shot**：让观众清楚看到攻击起点、轨迹和目标。
- **接触Shot**：强调拳、剑、枪、技能与目标发生关系。
- **反应Shot**：展示受击、失衡、闪避或心理变化。
- **环境Shot**：展示借墙、掩体、楼梯、车辆等如何改变动作。
- **尺度Shot**：当战斗真正升级时切到大全景。
- **情绪Shot**：终结前用50/85mm强调眼神、呼吸、伤势或决心。
- **终结Shot**：只承担高潮结果，不在高潮后继续增加新动作。

## 20｜剪辑逻辑

- **动作切**：利用挥拳、挥刀、人物穿镜或前景遮挡在运动中切换。
- **命中切**：命中前建立预期，命中后给结果或受击。
- **方向切**：继承运动方向，不突然换轴。
- **反应切**：关键攻击必须考虑受击者反应镜头。
- **空间切**：从近景切大全景必须重新揭示人物位置。
- **尺度切**：只在动作规模真正升级时使用。
- **情绪切**：终结前可短暂降低动作速度和镜头运动。

每次CUT都必须回答：**为什么现在切？切了以后观众多看懂了什么？**

## 21｜180°轴线与空间连续

- 默认A在画面左侧、B在右侧。除非用户明确要求越轴。
- 越轴必须通过摄影机绕行或空间重新建立来完成。
- 人物左右关系、攻击方向、逃避方向必须连续。
- 多人战斗必须建立每个人的位置、目标、攻击方向、移动方向和战术目的。
- 禁止所有人围着一个人无逻辑乱打。

## 22｜摄影机总原则

摄影机不是独立表演者。每个镜头都必须回答：“这个镜头为什么在这里？”

- 看清动作
- 强化速度
- 展示空间
- 强调重量
- 制造冲击
- 引导视线
- 展示技能规模
- 连接下一镜

禁止为了“高级”随机360°旋转。360°属于特殊镜头，不是默认动作。

## 24｜丝滑电影模式

当用户说“丝滑、高级、电影感、大片、一镜到底、流畅”，自动启用：

- 连续轨迹、Smooth Ease In/Out、自然惯性、主体跟随、轻微弧线、稳定摄影。
- 不随机旋转、不无意义抖动、不突然变焦、不突然停止。
- 不让主体无故离开画面，不破坏180°关系。
- 摄影机像在空气中滑行，而不是被疯狂甩动。

## 25｜焦距系统

| 焦距 | 用途 |
|---|---|
| 18–24mm | 巨物、史诗、强透视、近距离冲击、终极空间 |
| 28mm | 动作、环境互动、武侠、枪战空间 |
| 35mm | 电影动作主力、双人攻防 |
| 50mm | 人物关系、对峙、自然叙事 |
| 85mm | 眼神、命中、受伤、情绪 |
| 135mm | 远距离压缩、战场观察 |

## 26｜光圈、物距、景深

| 参数 | 效果 | 适用 |
|---|---|---|
| F1.2–F1.8 | 极浅景深 | 眼神、终结前情绪 |
| F2–F2.8 | 电影感、主体突出 | 人物动作 |
| F4 | 人物+环境平衡 | 标准动作 |
| F5.6 | 更深景深 | 中大型战斗 |
| F8 | 空间清晰 | 大型空间 |
| F11 | 史诗环境 | 战争/巨兽 |

| 物距 | 效果 |
|---|---|
| 近物距 | 强透视、攻击贴脸、前景冲击 |
| 中物距 | 双人动作、完整攻防 |
| 远物距 | 战斗空间 |
| 超远物距 | 巨兽、战争、终极技能 |

高速动作禁止全程F1.2；动作越复杂，越需要足够景深保证肢体与空间可读。

## 28｜景深动态

- 蓄力：浅景深。
- 第一轮交锋：中等景深。
- 高速连招：中深景深。
- 多人战斗：深景深。
- 大招：深景深。
- 终结情绪：重新浅景深。

## 29｜速度曲线与慢动作

- 默认：**Ease In → Accelerate → Peak → Ease Out**。
- 高潮可以使用：**Slow → Fast → Ultra Fast → Micro Slow Motion → Impact → Normal**。
- 慢动作只放在关键命中、武器碰撞、关键反击、跳跃最高点、技能释放、终结。
- 写实真人默认极短慢动作；3D动画可加入极短冲击帧、Smear、速度线、残影。
- 禁止整段慢动作。
- 动作越快，越要保证关键Pose清晰。
