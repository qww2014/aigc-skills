# 变量数据库：光圈 / 焦距 / 物距 + 组合矩阵

本文件是五变量模型的取值底座。所有区间、T 值、毫米数、米数都来自《AI电影运镜三变量 Skill Pro V2.0》，直接查表使用，不要自行发明参数。

## 一、光圈数据库（T值）

| T值档位 | 景深 | 效果 | 适用场景 |
| --- | --- | --- | --- |
| T1.2–T1.4 | 极浅景深 | 眼睛/面部/情绪特写，背景强虚化 | 梦境、浪漫、神秘 |
| T1.8–T2.0 | 浅景深 | 人物突出，人物与环境兼顾 | 人物高级感、情绪戏 |
| T2.8–T4 | 中浅景深 | 自然电影感，人物与空间都可读 | 人物行动、环境人物镜头 |
| T5.6 | 通用电影环境光圈 | 人物与空间关系较平衡 | 通用电影环境镜头 |
| T8 | 大景深 | 前后景都成立 | 建筑、群像、巨物、史诗环境 |
| T11–T16 | 极大景深 | 前中后景同时叙事 | 宏大景观、复杂空间 |

**动态规则：** 光圈变大（T值下降）= 景深变浅；光圈变小（T值上升）= 景深变深。

写提示词时，光圈要写成**变化**而不是固定值：起始 T 值 → 结束 T 值，并说明景深随之怎么变（例：T2.8→T1.8，背景逐渐虚化）。

## 二、焦距数据库（mm）

| 焦距 | 透视特性 | 适合内容 |
| --- | --- | --- |
| 14–20mm | 超广角，极强空间纵深和透视夸张 | 巨物、建筑、冲刺、穿越 |
| 24mm | 强空间感 | 史诗、动作、巨型场景和环境揭示 |
| 28–35mm | 电影感最实用区间 | 人物+环境、追逐、奇幻、古装、剧情 |
| 40–50mm | 自然、真实、接近人眼 | 现实主义和叙事 |
| 65–85mm | 背景压缩与虚化增强 | 人物、情绪、爱情、高级肖像 |
| 100–135mm | 强压缩 | 偷窥、危险、远距离情绪观察 |
| 200mm以上 | 极端压缩 | 巨兽、山脉、战场、体育、远距离窥视 |

焦距决定的是**视野与空间压缩**：焦距越小，视野越宽、纵深越夸张；焦距越大，视野越窄、空间被压缩、背景越贴向主体。

## 三、物距数据库与真实透视（m）

| 物距 | 透视特征 | 适合内容 |
| --- | --- | --- |
| 0.3–0.8m | 极近距离，前景透视极强 | 冲击、特写、压迫 |
| 0.8–1.5m | 近景人物，五官和环境透视明显 | 近景人物 |
| 1.5–3m | 中近景 | 最适合人物叙事 |
| 3–8m | 中远景 | 人物与环境平衡 |
| 8–30m | 环境人物、建筑、巨物建立 | 环境与巨物建立 |
| 30m以上 | 大远景 | 史诗、巨兽、群山、城市尺度 |

**关键规则：** 物距真正变化时，前后景相对运动和透视比例会变化；**仅改变焦距不能完全替代真实摄影机移动。**

所以“物距↓”必须伴随摄影机的真实推进，“物距↑”必须伴随真实后退——写成参数时要把摄影机位移和物距变化绑在一起写，不能只写焦距。

## 四、变量组合效果矩阵（10 条）

| # | 变量组合 | 视觉结果 | 典型用法 |
| --- | --- | --- | --- |
| 1 | 物距↓ + 焦距固定 + 光圈固定 | 真实推进，空间透视增强 | 进入、靠近、发现 |
| 2 | 物距↑ + 焦距固定 + 光圈固定 | 真实后退，人物融入环境 | 揭示世界、离别 |
| 3 | 物距↓ + 焦距↑ | 压迫、空间压缩、心理异常 | 希区柯克式效果 |
| 4 | 物距↑ + 焦距↓ | 空间突然打开 | 史诗揭示 |
| 5 | 物距↓ + 光圈T值下降 | 主体越来越突出，背景逐渐虚化 | 人物高光时刻 |
| 6 | 物距↑ + 光圈T值上升 | 人物逐渐融入完整环境 | 收尾、抽离 |
| 7 | 焦距↑ + 光圈T值下降 | 长焦浅景深 | 高级人物肖像 |
| 8 | 焦距↓ + 光圈T值上升 | 广角大景深 | 空间叙事 |
| 9 | 焦距↓ + 物距↓ + T值上升 | 强烈空间爆发、前景掠过 | 动作冲击 |
| 10 | 焦距↑ + 物距↑ + T值下降 | 远距离观察、压缩空间 | 人物从环境中被抽离 |

矩阵的用法：先确定这场戏要的**视觉结果**（第 3 列），再反查变量组合，最后落到具体 T 值 / mm / m 上。不要先选运镜名词再倒推效果。
