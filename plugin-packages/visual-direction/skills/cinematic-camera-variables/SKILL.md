# AI电影运镜三变量 Pro V2.0

光圈 × 焦距 × 物距 × 对焦 × 摄影机空间运动｜面向 AI 视频创作的小白一键调用系统。

本 Skill 把传统电影摄影中的光圈、焦距、物距、对焦、景深与摄影机运动，转换成 AI 视频模型可以执行的动态运镜语言。用户只需要用一句自然语言描述“人物、场景、动作、情绪和想要的效果”，Skill 自动完成摄影参数设计、运动逻辑、时间变化、镜头节奏和最终视频 Prompt。

适用：Seedance、Veo、Runway、可灵、即梦、Pika 及其他支持自然语言视频生成的模型。

## 何时调用

- 用户说“电影感运镜”“高级缓慢推进”，却只给了效果、没给任何参数
- 用户说“希区柯克变焦”，要主体稳定、背景剧烈伸缩的心理异常感
- 用户说“巨物揭示”“史诗感”，要让尺度对比和世界展开成立
- 用户说“人物高级感”，要人物肖像、浅景深、眼睛锁焦
- 用户说“梦境入现实”，要从浅景深虚化逐步转为空间与细节清晰
- 用户抱怨模型把运镜做成数字放大、画面乱晃、前后景关系矛盾、主体比例异常

## 核心模型：五变量

| 变量 | 决定什么 |
| --- | --- |
| 光圈 T值 | 景深、主体分离、背景虚化和视觉注意力 |
| 焦距 mm | 视野、透视表现、空间压缩和主体比例 |
| 物距 m | 真实透视变化，是“真推拉”和“假变焦”的关键 |
| 对焦 | 观众在每一时刻看哪里，以及前景、中景、背景之间的信息优先级 |
| 摄影机空间运动 | 画面中的真实空间变化，包括推进、后退、横移、升降、俯仰、环绕、跟随等 |

**必须优先设计“变量之间的变化关系”，而不是堆砌运镜名词。**

## 最重要的区分：真运镜 vs 假运镜

| 组合 | 名称 | 视觉结果 |
| --- | --- | --- |
| 摄影机推进 + 焦距固定 | 真正 Dolly In | 主体变大，同时透视关系发生真实变化 |
| 摄影机不动 + 焦距增加 | Zoom In | 主体变大但真实空间透视基本不变 |
| 摄影机后退 + 焦距减小 | 真正 Dolly Out + Wide | 空间被打开 |
| 摄影机推进 + 焦距同步增加 | Dolly Zoom 类空间效果 | 主体比例可被稳定，背景产生明显异常伸缩 |

> AI提示必须写清“摄影机真实移动”，防止模型把运镜理解成单纯数字放大。

## 一句话调用协议

| 用户说 | 自动输出 |
| --- | --- |
| “人物站在桃林里，给我一个高级电影感缓慢推进。” | 50–85mm、T2.8→T1.8、物距3m→1.5m、摄影机真实推进、眼睛锁焦、背景逐渐虚化。 |
| “一个男孩站在荒原，远处巨兽出现，要史诗感。” | 35mm/T8建立空间→24mm/T11扩大世界，摄影机缓慢后退，男孩逐渐变小，巨兽与环境形成尺度对比。 |
| “美女回头，要高级，不要乱晃。” | 65–85mm、T1.8、轻微真实弧线移动或稳定推进，焦点从肩部/轮廓转移至眼睛，避免无意义横移。 |

## 禁止事项（硬红线）

1. 禁止把数字放大当作摄影机推进。
2. 禁止只写‘电影感运镜’而不给变量。
3. 禁止无理由堆叠横移、旋转、环绕、升降、推拉。
4. 禁止在没有视觉目的的情况下高速旋转镜头。
5. 禁止人物脸部在广角极近距离下产生无意义畸变。
6. 禁止前后景关系在同一镜头内违反真实空间逻辑。
7. 禁止参数变化与视觉结果互相矛盾。
8. 禁止为了复杂而复杂：一个强变量组合往往比五个普通运镜叠加更高级。

## 输出模板（十项）

- 【运镜核心】：用一句话说明这次运镜解决什么视觉问题。
- 【摄影机运动】：明确真实空间移动方向、速度、轨迹。
- 【焦距变化】：起始mm→结束mm及变化目的。
- 【光圈变化】：起始T值→结束T值及景深变化。
- 【物距变化】：起始距离→结束距离及透视变化。
- 【对焦变化】：焦点从哪里转移到哪里。
- 【空间变化】：前景、中景、主体、背景分别如何变化。
- 【节奏】：慢/中/快，以及变化发生在哪个时间段。
- 【最终AI视频Prompt】：把全部信息整合成一整段可直接复制的提示词。
- 【负面约束】：禁止数字变焦、禁止无意义抖动、禁止错误透视、禁止人物变形、禁止背景瞬移、禁止主体比例异常。

## 核心口诀

- 物距决定真实空间变化。
- 焦距决定视野与空间压缩。
- 光圈决定景深与视觉注意力。
- 对焦决定观众看哪里。
- 摄影机运动决定空间关系。
- 五者结合，才是真正的电影运镜。

AI视频不是‘镜头动得越多越高级’，而是‘变量变化越有目的越高级’。
