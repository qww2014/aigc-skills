# 生成流程、输出格式与质量检查（小节 44–54）

> 来源：《AI ACTION SCALE V6.0 FINAL 电影级动作分镜导演 Skill》小节 44–54 重构。

## 44｜自动生成流程（30 步）

1. 解析用户需求。
2. 确定视觉媒介和写实/动画程度。
3. 识别动作类型。
4. 建立角色Combat DNA。
5. 确定战斗目标与胜负条件。
6. 建立空间地图。
7. 建立战术关系。
8. 建立动作因果链。
9. 生成动作Beat。
10. 建立动作接力。
11. 计算攻防与距离变化。
12. 计算受力、重量、惯性。
13. 计算武器物理。
14. 计算技能与特殊规则。
15. 加入环境交互。
16. 建立Shot分镜。
17. 为每个Shot选择景别、机位、焦距、光圈、物距。
18. 设计摄影机轨迹。
19. 设计镜头之间的剪辑入口和出口。
20. 加入速度曲线。
21. 加入关键慢动作/冲击帧。
22. 加入特效反馈。
23. 设计高潮。
24. 压缩结尾。
25. 检查180°轴线。
26. 检查角色连续性。
27. 检查动作连续性。
28. 检查镜头连续性。
29. 检查AI生成稳定性。
30. 最终整合成可复制Prompt。

## 45｜标准输出格式

当用户没有特殊要求时，默认输出以下三层：

- ① **一句话理解**：一句话说明这段动作的核心设计。
- ② **完整电影分镜**：严格按时间轴列出SHOT，每个Shot包含景别、机位、焦距、运镜、动作、结果、剪辑逻辑。
- ③ **最终AI视频Prompt**：把完整分镜压缩成一整段、可直接复制的Prompt。
- ④ **AI生成约束**：角色、武器、空间、手脚、方向、镜头、光线、连续性等。

如果用户明确说“只要Prompt”，则不解释，只输出最终一整段Prompt；但内部仍必须先完成分镜设计。

## 46｜标准分镜模板

```
【SHOT 01｜0.0–1.0秒】
景别：；机位：；焦距：；光圈：；物距：；画面任务：；
动作：A从____开始，执行____，与B发生____交互，结果是____；
运镜：摄影机从____向____运动，继承上一镜____方向；
速度：____；环境反馈：____；剪辑出口：在____瞬间切入下一镜。
```

后续SHOT按同样结构执行。

## 47｜最终Prompt固定结构

【视觉媒介】→【角色固定信息】→【空间关系】→【战斗目的】→【动作因果链】→【逐Shot时间轴】→【景别/机位/焦距/光圈/物距】→【摄影机轨迹】→【攻防与受力】→【武器/技能规则】→【环境反馈】→【速度曲线】→【慢动作/冲击帧】→【光影】→【连续性】→【AI生成约束】。

最终必须是一整段可直接复制的自然语言Prompt，不把专业参数变成互相矛盾的堆砌。

## 48｜AI稳定性约束

1. 角色脸、发型、服装、颜色、体型、身高、比例固定。
2. 武器外形、握持方式、数量、位置固定。
3. 左手右手、前脚后脚、身体朝向保持连续。
4. 角色不能瞬移，武器不能消失或凭空出现。
5. 避免多余手指、多余肢体、关节反转、身体拉伸。
6. 避免随机镜头旋转、随机变焦、随机切镜。
7. 避免动作方向突然反转。
8. 避免没有接触就产生受击。
9. 避免特效无来源出现。
10. 避免背景结构随机变化。
11. 避免光线方向突然改变。
12. 复杂动作拆成多个Shot，降低单镜头负载。

## 49｜最终质量检查器

| 模块 | 必须通过 |
|---|---|
| 剧情 | 战斗目的明确，结尾结果明确 |
| 动作 | 每个关键动作有意图、起手、交互、结果、反馈 |
| 因果 | 下一动作利用上一动作结果 |
| 物理 | 重量、惯性、重心、接触合理 |
| 战术 | 存在攻防、优势变化和至少一次有效战术调整 |
| 距离 | 距离变化有原因 |
| 空间 | A/B位置、攻击方向、移动方向清楚 |
| 轴线 | 180°关系稳定或有明确越轴过程 |
| 摄影 | 镜头服务动作，没有无意义炫技 |
| 分镜 | 每个Shot只有明确主要视觉任务 |
| 剪辑 | 每次CUT都有动作或信息理由 |
| 焦距 | 景别和焦距符合动作任务 |
| 景深 | 复杂动作不会因为过浅景深而丢失信息 |
| 速度 | 存在节奏变化，但慢动作克制 |
| 特效 | 来自动作/技能/环境，并放大而不是替代动作 |
| 连续性 | 角色、武器、手脚、方向、速度、光线一致 |
| 开头 | 按要求快速进入冲突 |
| 结尾 | 高潮后快速确认结果并CUT |
| AI | 没有明显瞬移、畸变、随机切镜和空间错乱 |

任何关键项不合格：自动回退到相关Shot重写，不允许靠增加特效掩盖问题。

## 50｜电影级动作设计的最终判断标准

不是“动作越多越厉害”。
不是“镜头越快越刺激”。
不是“特效越大越震撼”。

真正的电影级动作必须同时满足：

1. 观众看得懂谁在攻击、谁在防守。
2. 观众看得懂为什么下一动作发生。
3. 观众感觉到身体和武器的重量。
4. 观众知道人物在空间中的位置。
5. 摄影机让动作更有力量，而不是遮挡动作。
6. 镜头切换让信息更清楚，而不是让画面更乱。
7. 节奏有快慢，有准备，有峰值，有结果。
8. 每次命中都有反馈。
9. 每次反击都来自前一个结果。
10. 高潮真正改变战斗状态。
11. 高潮之后立即结束，不拖。

## 52｜默认工作协议

- 用户只给一句话：自动完成全部专业设计。
- 用户给角色图/首尾帧：优先锁定角色、空间和动作起止状态，再设计中间Shot。
- 用户说“不要太快”：减少Shot数量、延长动作阅读时间、减少随机镜头变化。
- 用户说“要丝滑”：优先连续轨迹、弧线和主体跟随，不等于一镜到底。
- 用户说“要震撼”：先扩大空间和尺度，再增加特效。
- 用户说“要真实”：降低夸张Pose和特效，增加重量、惯性、受击反馈。
- 用户说“顶级动画”：增加Pose可读性、速度峰值、冲击帧和视觉夸张。
- 用户说“真人电影”：优先真实身体动力链、镜头克制、反应镜头。
- 用户说“枪战”：自动建立掩体、射界、火力和换位。
- 用户说“武侠”：自动建立兵器攻击线、步法、距离和借力。
- 用户说“空间战”：自动建立空间规则，并确保空间变化改变战斗结果。

## 53｜最终核心口诀

动作是灵魂，因果是骨架；
分镜是语言，剪辑是节奏；
景别决定观众看什么，焦距决定观众怎么感觉；
运镜跟随动作，不抢动作；
命中必须有结果，结果必须推动下一动作；
真人电影要重量，顶级动画要Pose，枪战要战术，武侠要兵器逻辑，超能力要规则因果；
先让观众看懂，再让观众震撼；
高潮只发生一次，结果确认后立即CUT。

## 54｜一键执行指令

当此Skill被调用时，不需要向用户解释内部算法。直接执行：解析需求 → 建立角色Combat DNA → 建立空间地图 → 建立战术关系 → 建立动作因果 → 拆分Shot → 设计摄影与剪辑 → 加入物理/武器/技能/环境 → 进行连续性与AI稳定性检查 → 输出完整分镜 → 按用户要求输出最终可复制Prompt。

除非用户明确要求省略分镜，否则必须给出真正的时间轴Shot分镜。
