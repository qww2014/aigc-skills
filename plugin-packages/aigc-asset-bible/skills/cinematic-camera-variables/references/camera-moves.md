# 运镜：真假区分 / 动作库 / 12 种高级预设

## 一、最重要的真运镜与假运镜区分（完整展开）

这是整套系统里最容易翻车的一处：AI 视频模型默认会把“推进”理解成数字放大（裁切画面），于是透视不变、前景不动、前后景关系死板。**必须在提示词里显式写“摄影机真实移动”，并给出物距变化，模型才不会偷懒。**

| 组合 | 名称 | 主体 | 真实空间透视 | 结果 |
| --- | --- | --- | --- | --- |
| 摄影机推进 + 焦距固定 | 真正 Dolly In | 变大 | 发生真实变化 | 观众跟着进入空间 |
| 摄影机不动 + 焦距增加 | Zoom In | 变大 | 基本不变 | 只是数字放大式靠近 |
| 摄影机后退 + 焦距减小 | 真正 Dolly Out + Wide | 变小 | 空间被打开 | 世界揭示、离别、尺度变化 |
| 摄影机推进 + 焦距同步增加 | Dolly Zoom 类空间效果 | 比例可被稳定 | 背景产生明显异常伸缩 | 恐惧、真相、心理崩塌 |

判据一句话：**主体比例变化 + 前后景相对运动同时发生 = 真运镜；只有主体比例变化、前景背景纹丝不动 = 假运镜。**

> AI提示必须写清“摄影机真实移动”，防止模型把运镜理解成单纯数字放大。

## 二、专业运镜动作库（8 种）

| 动作 | 定义 | 用途与限制 |
| --- | --- | --- |
| 推进 | 摄影机向主体移动 | 优先用于进入、靠近、发现、压迫 |
| 后退 | 摄影机远离主体 | 用于揭示世界、孤独、离别、尺度变化 |
| 横移 | 保持与主体距离，横向平移 | 展示空间关系；避免无意义左右扫动 |
| 跟拍 | 与主体保持相对距离和方向 | 适合行走、奔跑、动作 |
| 环绕 | 围绕主体改变观察角度 | 适合人物登场、关系揭示；控制速度避免眩晕 |
| 升降 | 改变垂直空间关系 | 适合建筑、巨物、人物登场和空间揭示 |
| 俯拍/仰拍 | 改变权力关系与尺度感 | 巨物通常低机位更有重量 |
| 穿越 | 通过门、树、缝隙、人物之间的前景遮挡进入新空间 | 强调真实空间连续性 |

选动作的顺序：先问“这次运动要解决什么视觉问题”，再选动作；一个镜头只让**一个主运动**承担叙事，其他运动只能是辅助性的微调。

## 三、12 种高级/致命运镜预设

每条预设都是“参数组合 + 视觉结果 + 情绪用途”，可直接抄进提示词。

| # | 预设 | 参数 | 效果与用途 |
| --- | --- | --- | --- |
| ① | 希区柯克变焦 | 物距↓ + 焦距↑ | 人物比例尽量稳定，背景空间剧烈伸缩；用于恐惧、真相、心理崩塌 |
| ② | 世界打开 | 物距↑ + 焦距↓ + T值↑ | 人物从局部主体逐渐变成环境中的小点 |
| ③ | 神明降临 | 远距离35mm/T8建立世界，缓慢推进并向85mm/T2过渡 | 人物逐渐从世界中被“选出” |
| ④ | 巨物揭示 | 24–28mm/T8，低机位 | 先靠近局部，再后退或扩大视野揭示完整巨物 |
| ⑤ | 巨兽压迫 | 100–200mm长焦+远物距，随后缓慢推进 | 背景压缩，巨兽体量不断增加 |
| ⑥ | 空间爆炸 | 24mm/T8 | 摄影机快速真实推进，前景高速掠过，形成强纵深 |
| ⑦ | 人物被世界吞没 | 35mm/T8，持续后退 | 人物越来越小，环境越来越宏大 |
| ⑧ | 梦境入现实 | 85mm/T1.4浅景深开始，逐步向35mm/T5.6转化 | 空间和细节逐渐清晰 |
| ⑨ | 压迫逼近 | 85–135mm，摄影机真实靠近 | 背景强压缩，主体比例控制稳定 |
| ⑩ | 眼神锁定 | 50–85mm/T1.4–2 | 先环境浅清晰，随后焦点快速落到眼睛，注意力瞬间集中 |
| ⑪ | 空间穿越 | 24mm→35mm→50mm | 摄影机连续向前穿过前景、中景、主体，空间信息逐层变化 |
| ⑫ | 命运拉远 | 50mm/T2.8从人物近景开始，缓慢后退至24–35mm/T8大远景 | 人物被环境吞没 |

使用注意：

- ①⑨ 属于心理/压迫类，必须写清摄影机真实移动，否则模型只会做数字放大。
- ③④⑤⑦⑫ 属于尺度类，必须带**尺度参照物**（人、车、建筑、山体）和低机位，否则巨物没有体量。
- ⑧⑪ 属于转化类，必须写“起始状态→中间变化→最终状态”，只写终点参数模型不会做过渡。
- ⑩ 的核心是对焦转移，焦距和机位只服务于“焦点落到眼睛”这一下。
