# 景别基础：先认识"远、全、中、近、特"

## 两个基本定义

**分镜**：把一段故事安排成一个个镜头，说明每一镜拍谁、拍什么、怎么接。

**景别**：这一镜拍多大的范围，是分镜设计中的一项。

## 五档景别

**远景**——环境占主导，人物较小。适合交代地点、空间规模、人物与环境的关系，也能表现孤独、自由、壮阔。

**全景**——人物从头到脚完整入画。适合看全身动作、站位、走动，以及两个人之间的距离。

**中景**——通常取人物腰部以上。适合交代手部动作、人物互动和日常对话；动作在腰部以下时，需要适当放宽画面。

**近景**——通常取人物胸部或肩部以上。适合看清眼神、神情和情绪变化。

**特写**——突出面部或一个关键局部，如眼睛、手、钥匙、手机消息。适合强调重要信息和动作细节。

## 边界与免责

这些是入门时的常见划分，具体边界会随教材和拍摄对象有所变化。

"远景"不等于只要用广角，"特写"也不等于必须把背景全部虚化。
