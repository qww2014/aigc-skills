# 电影级动作分镜导演

把用户一句“想看什么打斗”，自动转化为真正可拍、可剪、可生成、可连续的电影级动作分镜（Shot 时间轴），并最终生成一整段可直接复制的 AI 视频 Prompt。

## 何时调用

- 用户要做打斗分镜、动作戏镜头表、动作戏 Prompt（真人电影 / 3D动画 / 枪战 / 武侠 / 仙侠 / 超能力 / 巨兽 / 机甲 / 战争 / 车辆追逐 / 体育动作）。
- 用户抱怨动作戏“看不懂谁打谁”“没有重量感”“镜头乱”“打斗像轮流摆拍”。
- 用户只说一句“想看什么打斗”，或只给角色图、首尾帧，需要补全成完整动作设计。
- 用户要求“丝滑 / 电影感 / 震撼 / 真实 / 动漫 / 快 / 慢”等模糊动作诉求，需要翻译成可执行镜头语言。
- 用户要求一镜到底、开场紧凑、结尾收束、15秒/30秒/60秒动作段落。

## 核心公式与最小单位

- 核心公式：**意图 → 动作 → 交互 → 结果 → 反馈 → 下一动作**。
- V6.0 的最小电影单位不是“动作”，而是 **Shot**。一个 Shot 原则 = **一个主要动作 + 一个主要结果 + 一个主要摄影任务**；复杂动作必须拆 Shot，任何超过 3 秒的复杂动作都必须先拆 Shot。
- **动作不是一坨文字；必须先成为 Shot 分镜，再成为最终 Prompt。**

## 十二原则（精简为可执行红线）

1. **动作第一**：先解决谁为什么做什么，以及动作造成什么结果。
2. **因果第一**：后一动作必须由前一动作产生的结果推动。
3. **分镜第一**：任何超过3秒的复杂动作都必须先拆Shot。
4. **动作连续性高于动作数量**：宁可少一个动作，也不能断掉速度、方向、重心、位置、武器和战术。
5. **摄影机服务动作**：看清、强化速度、展示空间、强调重量、制造冲击、引导视线，但不抢动作。
6. **受力必须可见**：攻击、格挡、碰撞、跌落、反弹、技能命中都必须产生身体或环境反馈。
7. **特效是反馈**：不能让特效替代动作。
8. **每个动作必须改变至少一项**：攻防、距离、位置、速度、重心、武器、战术、空间或环境。
9. **开头紧凑**：用户要求刺激、爽、大片时，第一秒就进入有效动作。
10. **中段升级**：必须发生至少一次战术变化；高级动作戏优先“优势→破解→反制→再反制”。
11. **结尾收束**：最后2–3秒进入高潮，最后0.5–1秒确认结果后CUT。
12. **先逻辑，后炫技**：任何随机旋转、无因果位移、无理由特效、无理由切镜都删除。

## 六步因果检查

每一个关键动作必须通过六步检查：

| 阶段 | 必须回答 | 示例 |
|---|---|---|
| 意图 | 角色为什么做？ | A想逼B离开掩体 |
| 动作 | 具体怎么做？ | A侧身探出、连续射击 |
| 交互 | 与谁/什么发生关系？ | 子弹压制B的掩体边缘 |
| 结果 | 发生了什么？ | B无法继续停留 |
| 反馈 | 身体/武器/环境发生什么？ | 碎屑飞散，B改变重心 |
| 下一动作 | 为什么现在做下一步？ | B借另一侧掩体转移 |

- 禁止：A攻击→B闪避→A突然换位置→B突然大招。
- 正确：A攻击→B闪避→A攻击落空产生惯性→B抓住空档→B反击→A被迫改变重心→利用环境恢复→再次攻击。

## Shot Engine 字段

每个 Shot 必须有：

1. SHOT编号
2. 时间码：精确到0.1秒
3. 景别
4. 机位高度与角度
5. 镜头焦距
6. 物距
7. 主要摄影机轨迹
8. 画面主任务
9. 人物动作
10. 交互对象
11. 结果与受力
12. 环境反馈
13. 速度曲线
14. 剪辑入口
15. 剪辑出口
16. 下一Shot如何继承方向、位置和速度

一个Shot原则：一个主要动作 + 一个主要结果 + 一个主要摄影任务。复杂动作必须拆Shot。

## 五套电影动作语言

| 类型 | 核心审美 | 必须突出 | 默认镜头语言 |
|---|---|---|---|
| 真人电影动作 | 真实重量、惯性、身体受力 | 起手、接触、受击、恢复 | 35mm主力，中景/近景，克制运镜 |
| 顶级3D动画 | Pose清晰、节奏鲜明、视觉夸张 | 关键Pose、动作峰值、冲击帧 | 24–35mm动态镜头，允许更强透视 |
| 枪战电影 | 战术关系、火力与掩体 | 射手/目标/掩体/弹着/换位 | 24–50mm交替，空间镜头与反应特写 |
| 武侠/兵器 | 距离、兵器攻击线、借力 | 剑线、格挡、回收、步法 | 28–50mm动作主镜，85mm命中/眼神 |
| 空间/超能力 | 规则改变战斗结果 | 能力触发、轨迹改变、尺度升级 | 近景规则说明→中景结果→24mm大全景 |

## 标准输出（三层）

- ① **一句话理解**：一句话说明这段动作的核心设计。
- ② **完整电影分镜**：严格按时间轴列出SHOT，每个Shot包含景别、机位、焦距、运镜、动作、结果、剪辑逻辑。
- ③ **最终AI视频Prompt**：把完整分镜压缩成一整段、可直接复制的Prompt。
- ④ **AI生成约束**：角色、武器、空间、手脚、方向、镜头、光线、连续性等。

如果用户明确说“只要Prompt”，则不解释，只输出最终一整段Prompt；但内部仍必须先完成分镜设计。

## 一键执行指令

当此Skill被调用时，不需要向用户解释内部算法。直接执行：解析需求 → 建立角色Combat DNA → 建立空间地图 → 建立战术关系 → 建立动作因果 → 拆分Shot → 设计摄影与剪辑 → 加入物理/武器/技能/环境 → 进行连续性与AI稳定性检查 → 输出完整分镜 → 按用户要求输出最终可复制Prompt。

除非用户明确要求省略分镜，否则必须给出真正的时间轴Shot分镜。
